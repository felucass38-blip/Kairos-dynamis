Muitos membros, um só corpo.

SÔMA vem do grego σῶμα, que significa corpo. É uma comunidade de fé que se reúne para louvar, fazer música e vestir a mesma camisa.

Porque, assim como o corpo é um e tem muitos membros, e todos os membros, sendo muitos, são um só corpo, assim é Cristo também.

O que fica no seu aparelho

Os itens da sacola ficam salvos só no seu navegador, para você não perder o pedido ao recarregar a página. Para apagar, é só esvaziar a sacola.

Pedidos e contato

Ao finalizar um pedido, você vai para o WhatsApp ou para o Instagram com a mensagem pronta. O que você mandar por lá, como nome, telefone e endereço, é usado só para combinar pagamento e entrega. Essas plataformas também seguem as políticas de privacidade delas.

Serviços de terceiros

As fontes do site são carregadas do Google Fonts. Os links para Spotify, YouTube e Instagram levam para sites com políticas próprias.
